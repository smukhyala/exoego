Does exocentric video reduce the labels needed?

Every action is filmed from a head-mounted camera and a fixed third-person camera at the same instant. The third-person view is never available at evaluation -- it is used only as unlabelled auxiliary signal during training. If it carries real information, the model should reach a given accuracy from fewer labelled egocentric clips.
