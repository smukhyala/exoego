The work

  • Apply for Ego-Exo4D access — 2 min, free option, may unlock later
  • Start AssemblyHands annotations download in background — small, and it gates everything
  • Agree repo layout data/ src/ results/, one branch, small commits
  • Copy World Context meta/ and chosen task clips from the USB to local SSD

The USB is a bottleneck. Re-reading 1080p video off it will throttle every later step. 590 GB free locally — use it.

Track A · OpenArm P1 · starts immediately

Current limit before position command. Always, no exceptions.

  • CAN bring-up: sudo ip link set can0 up type can bitrate 1000000, confirm candump can0 shows traffic
  • Enumerate motor IDs
  • Set torque/current limit to ~15% of rated before any motion command
  • Verify the limit clamps — stall a joint by hand. If it doesn't stall, the limit is not applied
  • One joint responds to a slow position command Gate G2
  • Gripper calibration: slow current-limited close, log current, detect range from current rise — never by commanding endpoints. Soft limits at 90% of range
  • Watchdog cuts on sustained high current; e-stop reachable at all times
  • Expose move_to(joint_targets) and home() as the only public API
  • IK against the OpenArm URDF via ikpy or pinocchio — fallback is reduced-DoF direct mapping

If G2 fails: train a grasp-moment classifier on World Context clips, run it on the Jetson against the arm's camera, and let it trigger a scripted motion. Dataset-trained perception gating real control still qualifies for the bonus track.

Track B · AssemblyHands P2

Synchronized ego + exo, 3D hand keypoints, intrinsics and extrinsics. No approval gate.

  • Download in order: annotations → one split of ego images → exo only for takes actually used. Not all 490K ego images
  • Loader: given a frame → ego image, exo images, 3D keypoints, intrinsics, extrinsics
  • Reproject 3D GT into ego and exo, overlay, eyeball it Gate G1
  • Ego-only 3D estimate — monocular, scale-ambiguous. MediaPipe or HaMeR
  • Exo triangulation across static cams using the provided extrinsics → metric 3D
  • Error vs ground truth for both T1 result
  • Distillation head: ego features → metric scale correction, supervised by exo-derived 3D. Minutes to train — this is what transfers

Track C · World Context P3

Ego-only industrial footage, fisheye, with calibrated gyro. This is what drives the arm.

  • Filter to calibration_status == "intrinsics_and_gyro" — 200 of 424 clips
  • Primary task bottle-surface-buffing — planar, repetitive, one grasp, lowest gripper risk. Backup component-alignment-sticker-application. Avoid garment-folding-*
  • Decode at 5 fps → undistort with Kannala-Brandt intrinsics → convert to grayscale, because AssemblyHands ego cams are monochrome
  • IMU: subtract bias (bias is dps, samples are rad/s — convert) → apply gyro→camera matrix M → apply time_offset_ms → integrate to orientation. Never apply the GPMF ORIN remap first
  • Hand detection rate on the chosen task Gate G3
  • Head-rotation-compensated 3D hand trajectory, smoothed
